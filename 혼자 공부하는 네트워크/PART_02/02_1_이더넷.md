# 02-1 이더넷
## 이더넷(Ethernet)

- 현대의 유선 LAN은 대부분 이더넷을 기반으로 구성된다.
- 유선 LAN을 구축할 때 사용하는 케이블은 이더넷 규격을 따름
- 데이터 링크 계층에서 주고받는 데이터 단위도 **이더넷 프레임** 형식을 따름

이더넷 국제 표준 기술 => **IEEE 802.3**

서로 다른 제조사의 네트워크 장비라도 같은 형식의 프레임을 주고받고 함께 동작할 수 있는 이유는 통신 매체와 네트워크 장비가 이더넷 표준을 준수하기 때문!!!

IEEE 802.3은 여러 이더넷 표준의 묶음이면서, 이더넷 표준화 작업을 수행하는 IEEE 이더넷 작업 그룹을 가리키기도 한다. 이더넷 기술이 발전하면서 표준도 계속 추가되고 있으며, 표준에 따라 지원 장비, 통신 매체, 전송 속도가 달라질 수 있다.

## 통신 매체 표기 형식

특정 이더넷 표준에 따라 구현된 통신 매체는 아래처럼 표기가 됨

```text
전송 속도BASE-추가 특성
```

예: `10BASE-T`, `1000BASE-SX`, `10GBASE-LR4`

### 1. 전송 속도

앞부분의 숫자는 전송 속도를 의미 <br>
숫자만 있으면 Mbps, 숫자 뒤에 `G`가 붙으면 Gbps 단위

| 표기 | 의미 |
| --- | --- |
| 10 | 10 Mbps |
| 100 | 100 Mbps |
| 1000 | 1000 Mbps (1 Gbps) |
| 2.5G | 2.5 Gbps |
| 5G | 5 Gbps |
| 10G | 10 Gbps |
| 40G | 40 Gbps |
| 100G | 100 Gbps |

따라서 `100BASE-T`는 100 Mbps를, `10GBASE-T`는 10 Gbps를 지원하는 통신 매체를 뜻한다.

### 2. BASE

- 베이스밴드(Baseband)의 약자
- 변조된 데이터를 통신 매체로 전송하는 방식 
- 일반적인 LAN 환경에서는 디지털 신호를 송수신하는 베이스밴드 방식을 사용하며, 대부분의 이더넷 통신 매체에서 `BASE`를 사용한다고 생각해도 됨


## 통신 매체 종류

| 추가 특성 표기 | 케이블 종류 | 특징 |
| --- | --- | --- |
| `C` | 동축 케이블 | 전기 신호를 이용하는 케이블 |
| `T` | 트위스티드 페어 케이블 | 구리선을 꼬아 만든 케이블 |
| `S` | 단파장 광섬유 케이블 | 빛을 이용하는 광섬유 케이블 |
| `L` | 장파장 광섬유 케이블 | 빛을 이용하는 광섬유 케이블 |


아래 예시

- `10BASE-T`: 10 Mbps를 지원하는 트위스티드 페어 케이블
- `1000BASE-SX`: 1000 Mbps를 지원하는 단파장 광섬유 케이블
- `1000BASE-LX`: 1000 Mbps를 지원하는 장파장 광섬유 케이블

이더넷 표준 이름과 통신 매체 표기가 항상 일대일로 대응하지는 않음

## 대표 IEEE 802.3 표준

| 표준 규격 | 대표 통신 매체 |
| --- | --- |
| IEEE 802.3i | `10BASE-T` |
| IEEE 802.3u | `100BASE-TX` |
| IEEE 802.3ab | `1000BASE-T` |
| IEEE 802.3bz | `2.5GBASE-T`, `5GBASE-T` |

| IEEE 802.3ae | `10GBASE-SR`, `10GBASE-LR` |

## 이더넷 프레임

- 이더넷 네트워크에서 데이터 링크 계층이 주고받는 PDU 
- 상위 계층에서 내려온 정보를 헤더와 트레일러로 감싸는 과정을 **캡슐화**
- 수신 측에서 헤더와 트레일러를 제거해 상위 계층으로 전달하는 과정을 **역캡슐화**

**이더넷 프레임의 구성**

| 구분 | 필드 | 크기 | 역할 |
| --- | --- | ---: | --- |
| 헤더 | 프리앰블(Preamble) | 8바이트 | 프레임의 시작 알림 및 송수신 동기화 |
| 헤더 | 수신지 MAC 주소 | 6바이트 | 프레임을 받을 네트워크 인터페이스 식별 |
| 헤더 | 송신지 MAC 주소 | 6바이트 | 프레임을 보낸 네트워크 인터페이스 식별 |
| 헤더 | 타입/길이 | 2바이트 | 상위 프로토콜의 종류 또는 데이터 길이 표시 |
| 페이로드 | 데이터 | 46~1500바이트 | 상위 계층에서 전달받은 데이터 |
| 트레일러 | FCS | 4바이트 | 오류 검출용 CRC 값 |


### 프리앰블

- 프리앰블은 이더넷 프레임의 시작을 알리는 8바이트(64비트) 정보
- 처음 7바이트는 `10101010` 패턴이며, 마지막 1바이트는 `10101011`
- 수신지는 이 패턴을 통해 이더넷 프레임이 도착했음을 알아차리고 송신지와 동기를 맞추게 됨

### 수신지 MAC 주소와 송신지 MAC 주소

- 데이터 링크 계층의 핵심 식별자
- 네트워크 인터페이스마다 부여되는 6바이트(48비트) 길이의 주소로, LAN 안에서 송신지와 수신지를 특정하는 데 사용한다. 

```text
A1:C2:E3:A4:C5:E6
```


### 타입/길이

이 필드는 값에 따라 **타입(Type)** 또는 **길이(Length)**를 말함

- 값이 1500(`0x05DC`) 이하이면: 데이터 필드의 길이
- 값이 1536(`0x0600`) 이상이면: 프레임이 캡슐화한 상위 프로토콜의 종류 -> 이더타입

**대표적인 이더타입**

| 타입(16진수) | 프로토콜 |
| --- | --- |
| `0800` | IPv4 |
| `86DD` | IPv6 |
| `0806` | ARP |

### 데이터

- 상위 계층에서 전달받은 내용
- 네트워크 계층의 데이터그램과 헤더를 합친 PDU 등이 이 부분에 있음
- 최대 크기는 1500바이트, 최소 46바이트 
    - 데이터가 46바이트보다 작으면 최소 크기를 맞추기 위해 보통 0으로 채운 패딩이 추가됨

### FCS

- 수신한 이더넷 프레임에 오류가 있는지 검사하기 위한 4바이트 필드
- 이 필드에는 **CRC(Cyclic Redundancy Check)** 값이 들어감

<br>

1. 송신지는 프리앰블을 제외한 프레임 필드 값을 바탕으로 CRC를 계산해 FCS에 기록한다.
2. 수신지는 수신 프레임에서 프리앰블과 FCS를 제외한 필드 값을 바탕으로 CRC를 다시 계산한다.
3. 계산한 값과 FCS의 값을 비교하고, 일치하지 않으면 전송 중 오류가 발생한 것으로 판단해 해당 프레임을 폐기한다.
