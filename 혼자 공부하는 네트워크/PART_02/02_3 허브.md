- 통신 매체를 통해 송수신되는 메세지는 다른 호스트에게 전달되는 과정에서 네트워크 장비를 거침
- 물리 계층에는 **허브**, 데이터 링크 계층 에는 **스위치**

![](../../IMG/혼자%20공부하는%20네트워크/PART_02/1.png)

</br></br>

## 주소개념 없는 물리 계층

- 송수신지를 특정할 수 있는 주소는 데이터 링크 계층부터 존재하기 때문에, 물리 계층에는 주소 개념이 없음
- **물리 계층에서는 호스트와 통신 매체 간의 연결과 통신 매체상의 송수신이 이루어질 뿐**
    - 송수신 되는 정보에 어떤 조작(송수신 내용 변경)이나 판단 X
- **데이터 링크 계층에 MAC주소 속함**
    - 데이터 링크의 장비나 그 이상의 장비 송수진지 특정 가능
    - 주소 바탕으로 송수신되는 정보에 대한 정보에 대한 조작 판단

 
![](../../IMG/혼자%20공부하는%20네트워크/PART_02/2.png)

</br></br>

## 허브

- **물리 계층으로 여러 대의 호스트를 연결하는 장치**
- 리피터 허브 or 이더넷 네트워크 허브는 이더넷 허브라고 부름
    
    ![](../../IMG/혼자%20공부하는%20네트워크/PART_02/3.png)
    
    - 위 그림에서 커넥터를 연결할 수 있는 네 개의 연결지점을 포트라고 함
        - 포트에 호스트와 연결된 통신 매체 연결할 수 있음

### 허브의 특징

- 오늘날 인터넷 환경에서 허브를 잘 사용하지 않지만 네트워크 개념을 내포하니 가볍게 알아두자~

#### 1. 전달받은 신호를 다른 모든 포트로 그대로 내보낸다

- 신호를 받으면 어떠한 조작, 판단하지 않고 **송신지를 제외한 모든 포트에 보냄**
    - 주소 개념 없기 때문
- **전달받은 호스트는 데이터 링크 계층에서 패킷의 MAC 주소 확인하고 자신과 관련없는 주소 폐기**

#### 2. 반이중 모드 통신한다

- **반이중 모드**
    - 마치 1차선 도로처럼 송수신을 번갈아 가면서 하는 통신 방식
    
    ![](../../IMG/혼자%20공부하는%20네트워크/PART_02/4.png)
    
    - A가 B에게 메세지를 송신할 때 호스트 B는 A에게 송신할 수 없음
    - ex) 무전기
- 전이중 모드
    - 양방향으로 할 수 있는 통신 방식
    
    ![](../../IMG/혼자%20공부하는%20네트워크/PART_02/5.png)
    

#### 콜리전 도메인

- **충돌이 발생할 수 있는 영역**
- 만약 동**시에 허브에 신호를 송신하면 충돌(collision, 콜리전) 발생**
- 허브에 호스트가 많이 연결되어 있을수록 충돌 발생 간으성 높음
    - 다른 호스트가 허브로 신호를 송신할 수 있기에

![](../../IMG/혼자%20공부하는%20네트워크/PART_02/6.png)

- 콜리전 도메인은 작을수록 발생할 가능성이 줄어들기 때문에 좋음
- 위 사진과 같이 허브에 연결된 모든 호스트가 하나의 콜리전 도메인에 속하는 것은 바람직하지 않음
- 허브의 넓은 콜리전 도메인으로 인한 문제를 해결하렴녀CSMA/CD 프로토콜을 이용하거나 스위치 장비 활용

#### **→ 허브는 여러 대의 호스트를 연결할 수 있는 물리 계층 장비, 전달받은 신호를 송신지 포트로 내보내고, 반이중 모드로 통신힌디. 허브에 연결된 모든 호스트는 하나의 콜리전 도메인에 속하는데, 범위가 클수록 충돌 발생 높아짐**


</br></br>

## CSMA/CD

- 허브에서 충돌이 발생하는 근본적 이유는 반이중 통신하기 때문
- **Carrier Sense Multiple Access with Collision의 약자로, 반이중 이더넷 네트워크에서 충돌을 방지하는 대표적인 프로토콜**

#### 1. CS는 Carrier Sense, 캐리어를 감지를 의미

- CSMA/CD 프로토콜을 사용하는 반이중 이더넷 네트워크에서 메세지를 보내기 전 현재 네트워크상에서 전송 중인 것이 있는지를 먼저 확인
    - 현재 통신 매체의 사용 가능 여부를 검사 → 이것이 캐리어 감지
    - 반송파 감지를 의미, “통신 매체 상에서 흐르는 신호 감지”
    
    ![](../../IMG/혼자%20공부하는%20네트워크/PART_02/7.png)
    

#### 2. MA는 Multiple Access, 다중 접근을 의미

- 복수의 호스트가 네트워크에 접근하려는 상황을 다중 접근이라하며, 이때 충돌 발생

![](../../IMG/혼자%20공부하는%20네트워크/PART_02/8.png)

#### 3. CD는 Collision Detection, 충돌 검출을 의미

- **충돌이 발생하는 것을 충돌 검출**이라고 함
- 충돌을 감지하면 전송이 중단하고, 충돌을 검출한 호스트는 다른 이들에게 충돌이 발생했음을 알리고자 잼 신호라는 특별한 신호를 보냄
    - 그리고 임의의 시간동안 기다린 뒤에 다시 전송
    
    ![](../../IMG/혼자%20공부하는%20네트워크/PART_02/9.png)
    

#### 반이중 이더넷 네트워크에서 CSMA/CD 프로토콜을 사용하면

호스트가 메세지를 전송하기 전,

1. **먼저 현재 전송이 가능한 상태인지 확인**
2. **다른 호스트가 전송 중이지 않을 때 메세지 전송**
3. **다수의 호스트가 접근하여 충돌이 발생하면 임의의 시간만큼 대기 후 다시 전송**
