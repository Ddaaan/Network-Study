# 07-3_무선 네트워크

## 1. 무선 네트워크를 이루는 것들

- 카페에서 노트북, 스마트폰은 거의 다 선 없이 인터넷을 씀 → 무선 네트워크
- 유선 네트워크에 연결 매체, 표준, 장비가 있듯 무선 네트워크도 마찬가지임

| 구분 | 유선 | 무선 |
| --- | --- | --- |
| 연결 매체 (신호가 지나가는 길) | 케이블 | 전파 |
| 표준 | IEEE 802.3 | IEEE 802.11 |
| 기술 | 이더넷 | 와이파이(Wi-Fi) |
| 장비 | 스위치 등 | AP |

## 2. 전파와 주파수

### 전파 (radio wave)

- 무선 통신의 바탕이 되는 것
- 약 3kHz ~ 3THz 진동수를 가진 전자기파
- 쉽게 말해 “눈에 안 보이는 전자기파의 한 종류”
- TV, 라디오, 무전기, 노트북, 스마트폰 모두 전파로 통신함
- 지금 이 순간에도 주변 공간에 전파가 잔뜩 흐르고 있음
- 대부분 기기가 만들어 내지만, 번개, 태양, 우주에서도 자연적으로 생김

### 주파수 대역

- 여러 기기가 동시에 전파를 쓰면 같은 공간에 신호가 뒤섞임
- 그래서 신호를 구분하려고 용도별로 쓸 주파수 구간을 미리 정해 둠 → 주파수 대역
- 어떤 대역을 어디에 쓸지는 나라마다 다름
- 아래는 2020년 기준 대한민국 주파수 분배도표. 외울 필요 없음
- 방송용, 위성 통신용, 항공·해양 통신용 등으로 나뉘어 있다는 것만 알면 됨

### 자연 전파와 잡음

- 번개, 태양 활동으로 생긴 전파의 주파수가 통신용 대역과 우연히 겹치면 잡음이 생김
- 번개 치는 날 라디오에서 “지직” 소리가 나고 음질이 나빠지는 이유임

## 3. 와이파이와 802.11

### IEEE 802.11

- 유선 LAN 표준: IEEE 802.3 (802.3u, 802.3ab처럼 뒤에 알파벳으로 세부 규격 구분)
- 무선 LAN 표준: IEEE 802.11 (802.11b, 802.11g처럼 똑같이 뒤 알파벳으로 구분)
- 802.11은 대부분 2.4GHz, 5GHz 대역을 씀
- 와이파이 목록에 “2.4G”, “5G”가 붙어 있는 게 이 때문임
- 802.11 버전에 따라 주파수, 전송 속도, 대역폭, 전송 거리, 변조 방식 등이 달라짐

| 표준 규격 | 주파수 대역 | 최대 전송 속도 |
| --- | --- | --- |
| IEEE 802.11a | 5GHz | 54Mbps |
| IEEE 802.11g | 2.4GHz | 54Mbps |
| IEEE 802.11n | 2.4/5GHz | 450Mbps |
| IEEE 802.11ac | 5GHz | 6.9Gbps |
| IEEE 802.11ax | 2.4/5/6GHz | 9.6Gbps |
| IEEE 802.11be | 2.4/5/6GHz | 46.1Gbps |
- 참고
    - 변조(modulation): 정보를 원하는 형태의 신호로 바꾸는 것
    - 복조(demodulation): 변조된 신호를 원래 정보로 되돌리는 것

### 와이파이 (Wi-Fi)

- 요즘은 “802.11 표준을 따르는 무선 LAN 기술”이라는 뜻으로 많이 씀
- 원래는 와이파이 얼라이언스(Wi-Fi Alliance)라는 비영리단체의 상표(브랜드) 이름임
- 세대별로 “와이파이 4”, “와이파이 5”처럼 부르고, 세대마다 따르는 802.11 규격이 다름

| 세대 이름 | 표준 규격 |
| --- | --- |
| Wi-Fi 7 | IEEE 802.11be |
| Wi-Fi 6 | IEEE 802.11ax |
| Wi-Fi 5 | IEEE 802.11ac |
| Wi-Fi 4 | IEEE 802.11n |

### 와이파이 = 인증 마크

- 제품에 와이파이 인증 마크가 붙어 있으면
    - 그 제품이 어떤 802.11 규격을 지켰는지 알 수 있음
    - 다른 제품과 잘 호환되는지도 알 수 있음
- 그래서 무선 LAN 제품을 만든 회사는 인증 시험을 통과해서 인증과 로고 사용 권한을 받음

![Wi-Fi CERTIFIED 인증시험 안내 화면](../../IMG/혼자%20공부하는%20네트워크/PART_07/03/f8fc9ad9-fe57-42d3-9cc2-2c51efb92295.png)

- 윈도우 노트북에서는 무선 네트워크 속성에서 와이파이 버전과 802.11 규격을 확인할 수 있음
(아래 예시: 프로토콜 = Wi-Fi 5(802.11ac), 네트워크 대역 = 5GHz, 채널 = 48)

![윈도우 무선 네트워크 속성 화면](../../IMG/혼자%20공부하는%20네트워크/PART_07/03/a8c07815-9a3c-490e-9fd1-20a764ce8101.png)

### 참고: 2.4GHz vs 5GHz, 뭐가 더 좋나

- 답은 “상황에 따라 다름”

| 구분 | 2.4GHz | 5GHz |
| --- | --- | --- |
| 속도 | 느린 편 | 빠른 편 |
| 장애물 영향 | 덜 받음 | 크게 받음 |
- 이유는 회절성 때문임
    - 회절성: 파동이 장애물이나 좁은 틈을 지날 때 그 뒤편까지 퍼져 나가는 성질
    - 주파수가 낮을수록(2.4GHz) 회절이 잘 되고, 높을수록(5GHz) 잘 안 됨
    - 전파뿐 아니라 소리, 빛 같은 다른 파동도 마찬가지임

![5GHz는 틈 뒤로 좁게, 2.4GHz는 넓게 퍼지는 모습](../../IMG/혼자%20공부하는%20네트워크/PART_07/03/da640796-6c3e-46c0-80f5-ae6117c84731.png)

- 공유기와 기기 사이에 벽, 장애물이 많으면 5GHz 신호는 금방 약해짐
(앞의 와이파이 목록에서도 5G 신호가 더 약하게 보임)
- 결론
    - 장애물이 많다 → 2.4GHz
    - 장애물이 적고 속도가 중요하다 → 5GHz

## 4. 채널 (channel)

- 같은 2.4GHz(또는 5GHz) 대역 안에도 서로 다른 무선 네트워크가 여러 개 있을 수 있음
- 이 네트워크들이 서로 신호를 방해(간섭)하면 안 됨
- 그래서 2.4GHz, 5GHz 대역을 채널이라는 더 작은 구간으로 한 번 더 나눠서 통신함
- 채널마다 번호가 붙어 있음

![2.4GHz 채널 1~12와 5GHz 채널 36~48](../../IMG/혼자%20공부하는%20네트워크/PART_07/03/9ad71b1e-b40f-4c2e-a2df-3eada2a3399b.png)

- 그림 읽는 법
    - 포물선 하나 = 채널 하나
    - 포물선 위 숫자 = 채널 번호
    - 같은 2.4GHz라도 채널에 따라 실제 주파수가 조금씩 다름 (예: 1번 2.412GHz, 6번 2.437GHz)

### 채널 고르기

- 보통 자동으로 정해지지만 직접 설정할 수도 있음
- 같은 공간에 같은 대역의 네트워크가 여러 개면 겹치지 않는 채널을 쓰는 게 좋음
    - 예: 1, 6, 11번 채널은 서로 겹치지 않음
    - 반대로 1, 2, 3번을 같이 쓰면 많이 겹쳐서 간섭이 자주 생기고 통신이 느려짐
- 간섭이 많은 채널은 성능 저하의 주요 원인임

## 5. AP와 서비스 셋

### AP (Access Point, 무선 액세스 포인트)

- 무선 기기들을 연결해서 무선 네트워크를 만드는 장치
- 집에 있는 무선 공유기가 바로 AP 역할을 함
- 보통 유선 케이블을 꽂는 곳도 있어서 유선 네트워크와 무선 네트워크를 이어 주는 역할도 함

![AP 장비 모습](../../IMG/혼자%20공부하는%20네트워크/PART_07/03/01dc213a-4aa1-4c33-946c-f9ee8742a4ea.png)

### 인프라스트럭처 모드 (infrastructure mode)

- 무선 기기들이 AP를 거쳐서 인터넷에 접속하거나 서로 메시지를 주고받는 방식
- 즉, AP가 중간에서 통신을 이어 줌(중개)
- 오늘날 대부분의 무선 LAN이 이 방식임

![기기들이 AP를 거쳐 인터넷과 통신하는 모습](../../IMG/혼자%20공부하는%20네트워크/PART_07/03/2e01b91a-96c7-4bb6-8272-4fc4d2e63b70.png)

- 참고: AP 없이 기기끼리 1:1로 직접 통신하는 방식도 있음 → 애드 혹 모드(Ad Hoc mode)

### 서비스 셋 (Service Set)

- AP와 거기에 연결된 기기들을 묶은 무리
- 같은 서비스 셋에 속한 기기 = 같은 무선 네트워크에 속한 기기

### SSID (Service Set Identifier, 서비스 셋 식별자)

- 서비스 셋이 여러 개면 서로 구분할 방법이 필요함 → SSID
- 무선 네트워크마다 붙은 고유한 이름
- 우리가 흔히 보는 “와이파이 이름”이 바로 SSID임
- 무선 네트워크 속성 화면에서도 SSID 항목에 와이파이 이름이 적혀 있음

![SSID A, B, C 세 무선 네트워크가 각자 이름을 알리는 모습](../../IMG/혼자%20공부하는%20네트워크/PART_07/03/45983766-807c-4692-b6f2-dbd0aa8fc509.png)

### 참고: BSS와 ESS

- BSS(Basic Service Set): AP 하나로 만든 무선 LAN
- ESS(Extended Service Set): AP 여러 개로 만든 무선 LAN
- 이 책에서 말하는 서비스 셋, 무선 LAN, 무선 네트워크는 기본적으로 BSS 기준임

## 6. 비컨 프레임 (beacon frame)

- AP는 “나 여기 있어”를 계속 알려야 함
- 안 알리면 기기들은 접속할 수 있는 무선 네트워크가 있는지조차 모름
- 그래서 AP는 주변 모두에게 자기를 알리는 메시지를 주기적으로 뿌림(브로드캐스트)
- 이 메시지가 비컨 프레임임
- 안에 SSID, AP의 MAC 주소 등이 들어 있음
- 폰이나 노트북에 와이파이 목록이 뜨는 건 주변 AP들의 비컨 프레임을 받았기 때문임

![스마트폰이 AP들의 비컨 프레임을 받고 A, B, C 와이파이를 발견하는 모습](../../IMG/혼자%20공부하는%20네트워크/PART_07/03/7a413b03-ccc6-4a45-b864-5265dfb8219f.png)

## 핵심 정리

- 전파: 정보를 무선으로 실어 나르는 것. 통신용 주파수 대역은 미리 정해져 있음
- 802.11: 무선 LAN의 표준 규격
- 와이파이: 특정 802.11 규격을 지키는 기술 (원래는 Wi-Fi Alliance의 브랜드)
- 채널: 무선 네트워크가 쓰는 작은 주파수 구간. 번호로 구분함
- AP: 무선 기기들을 연결하는 장치
- 서비스 셋: AP와 연결된 기기들의 묶음. SSID로 구분함
- 비컨 프레임: AP가 자기 존재를 알리려고 브로드캐스트하는 메시지
