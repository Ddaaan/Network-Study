# 마무리 정리

# 1장. 컴퓨터 네트워크 시작하기

- 컴퓨터 네트워크 (computer network) : 여러 장치가 서로 연결되어 정보를 주고받는 통신망.
- 인터넷 (internet) : 여러 네트워크가 연결된 네트워크.
- 네트워크 구조 (network structure) : 호스트 네트워크 장비, 통신 매체, 메세지로 구성된 그래프 형태를 띰.
    
    ![image.png](../IMG/혼자%20공부하는%20네트워크/LAST/image.png)
    
- LAN (Local Area Network) : 가까운 지역을 연결한 근거리 통신망. 가정, 기업, 학교처럼 한정된 공간에서의 네트워크.
- WAN (Wide Area Network) : 먼 지역을 연결한 광역 통신망(인터넷은 WAN으로 분류).
- 회선 교환 네트워크 (circuit switching network) : 메세지를 주고받기 전, 회선 설정을 통한 연결을 확립한 뒤 송수신하는 네트워크.
- 패킷 교환 네트워크 (packet switching network): 메세지를 패킷 단위로 쪼개어 송수신하는 네트워크(오늘날의 대부분 인터넷 환경).
- 패킷 (packet) : 헤더, 페이로드, 때로는 트레일러로 구성.
- 프로토콜 (protocol) : 통신하기 위해 지켜야하는 노트 간의 합의된 통신 규칙.
- 통신 규칙 : 프로토콜마다 목적과 특징이 달라서 헤더도 달라짐.
- 네트워크 참조 모델 (network reference model) : 네트워크의 전송 단계를 계층적으로 표현한 모델.
    
    ![image.png](../IMG/혼자%20공부하는%20네트워크/LAST/image%201.png)
    
- 캡슐화 (encapsulation) : 데이터 전송 과정에서 헤더(및 트레일러)를 추가해 나가는 과정.
- 역캡슐화 (decapsulation) : 캡슐화 과정에서 붙인 헤더(및 트레일러)를 제거하는 과정.
- PDU (Protocol Data Unit) : 네트워크 참조 모델의 각 계층에서 송수신되는 메세지 단위.
    
    ![image.png](../IMG/혼자%20공부하는%20네트워크/LAST/image%202.png)
    

# 2장. 물리 계층과 데이터 링크 계층

- 이더넷 (Ethernet) : 연결 매체의 규격(표쥰 구격=IEEE 802.3), 송수신되는 프레임의 형태 등을 정의한 네트워크 기술.
    
    이더넷 통신 매체의 경우 : `*전송속도BASE-추가특성*` 형식으로 표기.
    
- 이더넷 프레임 (Ethernet frame) : 이더넷에서 송수신되는 프레임 형태.
    
    ![image.png](../IMG/혼자%20공부하는%20네트워크/LAST/image%203.png)
    
- MAC 주소 (MAC address) : 네트워크 인터페이스마다 부여되는 물리적 주소.
    
    6바이트(48비트) 16진수 열두 자리로 구성 - `*AB:CD:EF:AB:CD:EF` .*
    
- NIC (Network Interface Controller) : 호스트와 통신 매체 사이의 인터페이스 역할을 담당하는 네트워크 장비.
- 트위스티드 페어 케이블 (twisted pair cable) : 전기적 신호를 주고받는 유선 연결 매체.
    
    실드(브레이드 실드-S, 포일 실드-F, 무실드-U, `*XX/YTP*`로 표기)나 카테고리에 따라 구분 가능.
    
    | 특징 | Cat5 | Cat5e | Cat6 | Cat6a | Cat7 | Cat8 |
    | --- | --- | --- | --- | --- | --- | --- |
    | 지원 대역폭 | 100MHz | 100MHz | 250MHz | 500MHz | 600MHz | 2GHz |
    | 주요 대응 규격 | 100BASE-TX | 1000BASE-T | 1000BASE-TX | 10GBASE-T | 10GBASE-T | 40GBASE-T |
    | 전송 속도 | 100Mbps | 1Gbps | 1Gbps | 10Gbps | 10Gbps | 40Gbps |
- 광섬유 케이블 (fiber optic cable) : 광신호를 주고받는 유선 연결 매체
    
    싱글 모드 광섬유 케이블과 멀티 모드 광섬유 케이블 존재.
    
- 허브 (hub) : 물리 계층(주소 개념이 없음)의 네트워크 장비. 반이중 모드로 통신하며, 전달받은 신호를 다른 모든 포트로 내보내기만 한다. 하나의 허브에서 연결된 호스트들이 동시에 신호를 송신하면 충돌이 발생하고, 연결된 모든 호스트는 같은 콜리전 도메인(충돌이 발생할 수 있는 영역)에 속한다.
- 반이중 모드 통신 (half duplex mode communication) : 데이터를 한 번에 한 방향으로만 전송할 수 있는 통신 방식.
- 전이중 모드 통신 (full duplex mode communication) : 데이터를 동시에 양방향으로 전송할 수 있는 통신 방식.
- CSMA/CD (Carrier Sense Multiple Access with Collision Detection) : 반이중 이더넷의 충돌 방지 프로토콜. 충돌 발생 시 임의의 시간동안 대기 후 재전송.
- 스위치 (switch) 데이터 링크 계층(주소 개념이 있음-MAC주소)의 네트워크 장비. 전이중 모드로 통신하며, MAC 주소 테이블으 바탕으로 MAC 주소를 학습.
- VLAN (Virtual LAN) : 가상의 LAN. 스위치 한 대로 가상의 LAN을 만드는 방식.
- 포트 기반 VLAN : 연결된 포트가 호스트가 속할 VLAN을 결정.
- MAC 기반 VALN : 송수신하는 프레임 속 주소가호스트가 속할 VLAN을 결정.

# 3장. 네트워크 계층

- 인트넷 프로토콜 (IP; Internet Protocol) : 주소 지정과 단편화를 수행하는 네트워크 계층의 프로토콜.
    
    ![image.png](../IMG/혼자%20공부하는%20네트워크/LAST/image%204.png)
    
- MTU (Maximum Transmission Unit) : 한 번에 전송 가능한 IP 패킷의 최대 크기. 일반적으로 1500바이트이며, MTU 크기 이하로 나누어진 패킷은 수신지에 도착하면 다시 재조합.
- ARP (Address Resolution Protocol) : IP 주소를 MAC 주소에 대응ㅎ기 위해 사용되는 프로토콜.
    
    ARP의 동작순서 ① ARP 요청 (브로드캐스트 메세지) ② ARP 응답 ③ ARP 테이블 갱신
    
- 클래스풀 주소 체계 (classful addressing) : 클래스별로 네트워크 크기를 구분하는 IP 주소 체계. A클래스, B클래스, C클래스로 네트워크와 호스트 주소를 구분.
    
    ![image.png](../IMG/혼자%20공부하는%20네트워크/LAST/image%205.png)
    
- 클래스리스 주소 체계 (classless addressing) : 클래스에 구애받지 않고 네트워크를 조금 더 정교하게 나눌 수 있는 IP 주소 체계. 서브넷 마스크(IP 주소상에서 네트워크 주소는 1, 호스트 주소는 0으로 표기한 비트열)로 네트워크와 호스트 주소를 구분.
- 공인 IP 주소 (public IP address) : 전 세계에서 고유한 IP 주소. 일반적으로 인터넷을 이용할 대 사용하는 주소로 ISP나 공인 IP 주소 할당 기관을 통해 할당.
- 사설 IP 주소 (private IP address) : 사설 네트워크에서 사용하는 IP 주소. 사설 IP 주소로 살용할 수 있는 IP 주소 대역이 정해져있다.
    
    ![image.png](../IMG/혼자%20공부하는%20네트워크/LAST/image%206.png)
    
- 정적 IP 주소 (static IP address) : 호스트에 직접 부여한 고정된 IP 주소. 일반적으로 IP 주소, 서브넷 마스크, 게이트웨이(라우터) 주소, DNS 주소를 입력해서 부여.
- 동적 IP 주소 (dynamic IP address) : 호스트에 자동으로 부여된 IP 주소. DHCP를 통해 IP 주소를 임대. 임대 받은 IP 주소에는 임대 기간이 존재.
- DHCP : 동적 IP 주소 할당을 위해 사용되는 프로토콜.
- 라우터 (router) : 네트워크 계층의 대표 장비. 패킷이 이동할 최적의 경로(이를 위해 라우팅 테이블 활용)를 설정하고 그 경로로 패킷을 내보낸다.
- 라우팅 테이블 (routing table) : 특정 수신지까지 도달하기 위한 정보를 명시한 표와 같은 정보. 일반적으로 수신지 IP 주소와 서브넷 마스크 ,다음 홉, 네트워크 인터페이스, 메트릭이 명시.
- 라우팅 프로토콜 (routing protocol) : 패킷이 이동할 최적의 경로를 찾기 위한 프로토코. AS 내에서 수행되느냐, 외부에서 수행이 가능하냐에 따라 IGP, EGP로 나누어 짐.
    
    IGP : 거리 벡터를 활용하는 RIP, 링크 상태를 활용하는 OSPF
    
    EGP : AS 간의 통신에서 사용되는 BGP
    

# 4장. 전송 계층

- 신뢰할 수 없는 프로토콜 (unreliable protocol) : 패킷이 수신지까지 제대로 전송되었다는 확인을 하지 않는 프로토콜. 보완하는 프로토콜 - 전송 계층의 TCP.
- 비연결형 프로토콬 (connectionless protocol) : 송수신 가정에서 사전 연결 수립 작업을 거치지 않는 전송 특성.
- 포트 (port) : 응용 계층의 애플리케이션 프로세스를 식별하는 정보.
    
    ![image.png](../IMG/혼자%20공부하는%20네트워크/LAST/image%207.png)
    
- NAT (Network Address Translation) : IP 주소를 변환하는 기술. 포트 기반의 NAT를 NAPT라고 하며, NAPT는 IP 주소와 더불어 포트 번호도 함께 변환하는 NAT.
- 포트 포워딩 (port forwarding) : 네트워크 내 호스트에 IP 주소와 포트 번호를 미리 할당하고, 해당 IP 주소:포트 번호에 패킷을 전달하는 기능.
- ICMP (Internet Control Message Protocol) : IP의 신뢰할 수 없는 전송 특성과 비연겨형 전송 특성을 보완하기 위해 전송 과정의 피드백 메세지를제공하는 프로토콜.
- TCP 순서 번호 (TCP sequence number) : 송수신되는 세그먼트의 올바른 순서를 보장하기 위해 세그먼트 데이터의 첫 바이트에 부여되는 번호.
- TCP 확인 응답 번호 (TCP acknowledgment number) : TCP 순서 번호에 대한 응답으로, 다음으로 수신하기를 기대하는 순서 번호.
- TCP 연결 수립 (TCP connection establishment) : 3way-handshake을 통한 연결 수립. SYN, SYN+ACK, ACK 세그먼트를 주고받으며 연결 수립.
    
    ![image.png](../IMG/혼자%20공부하는%20네트워크/LAST/image%208.png)
    
- TCP 연결 종료 (TCP connection termination) : 송수신 호스트가 각자 한 번씩 FIN과 ACK를 주고받으며 종룍 이루어진다.
    
    ![image.png](../IMG/혼자%20공부하는%20네트워크/LAST/image%209.png)
    
- TCP 상태 (TCP State) : 현재 어떤 통신 과정에 있는지 나타내는 정보.
    
    ![image.png](../IMG/혼자%20공부하는%20네트워크/LAST/image%2010.png)
    
- 재전송 기반 오류 제어 (retransmission based error control) : 중복된 ACK 세그먼트를 수신했을 때 오류 감지. 타임아웃이 발생했을 때 오류 감지. 누적 확인 응담(Go-Back-N ARQ), 선택적 확인 응답(Selective Repeat ARQ)를 통해 오류가 발생한 세그먼트 재전송 요구.
- 흐름 제어 (flow control) : 수신자의 처리 속도를 고려하며 전송하는 방식. 슬라이딩 윈도우 사용.
- 혼잡 제어 (congestion control) : 네트워크의 혼잡도를 판단하고 혼잡한 정도에 따라 전송량을 조절하는 방식. 다양한 혼잡 제어 알고리즘(느린 시작, 혼잡 회피, 빠른 회복 등의 알고리즘)이 사용.
- 명시적 혼잡 알림 (ECN; Explicit Congestion Notification) : 네트워크 중간 장치(주로 라우터)의 도움을 받아 혼잡 제어를 수행하는 방식.

# 5장. 응용 계층

- 도메인 네임 (domain name) : IP 주소와 대응되는 문자열 형태의 호스트 특정 정보.
    
    ![image.png](../IMG/혼자%20공부하는%20네트워크/LAST/image%2011.png)
    
- 네임 서버 (name server) : 도메인 네임을 관리하는 서버. 계층적(루트 네임 서버, TLD 네임 서버 등)으로 구성.
- 도메인 네임 시스템 (DNS; Domain Name System) : 계층적이고 분산된 도메인 네임 대한 관리 체계. 도메인 네임을 관리하는 프로토콜 지칭.
- 자원 (resource) : 네트워크상의 메세지를 통해 송수신하고자 하는 최종 대상.
- URI (Uniform Resource Identifier) : 자원을 식별할 수 있는 정보.
    
    URL : 위치를 기반으로 자원 식별
    
    ![image.png](../IMG/혼자%20공부하는%20네트워크/LAST/image%2012.png)
    
    URN : 이름을 기반으로 자원 식별
    
- HTTP (HyperText Transfer Protocol) : 응용 계층에서 정보를 주고받기 위한 프로토콜.
    
    특징 : 요청-응답 기반, 미디어 독립적, 상태 유지하지 않음, 지속 연결 기능 제공
    
- HTTP 메서드 (HTTP method) : 클라이언트가 서버의 자원에 대해 수행하 작업의 종류
    
    ![image.png](../IMG/혼자%20공부하는%20네트워크/LAST/image%2013.png)
    
- HTTP 상태 코드 (HTTP status code) : 요청 메시지에 대한 결과를 나타내는 세 자리 정수. 백의자릿수로 상태 코드의 유형을 알 수 있다.
    
    ![image.png](../IMG/혼자%20공부하는%20네트워크/LAST/image%2014.png)
    
- HTTP 헤더 (HTTP header) : HTTP 메시지에 대한 부가 정보. 일반적으로 한 HTTP 메시지에 다양한 헤더가 포함된다.
    
    ![image.png](../IMG/혼자%20공부하는%20네트워크/LAST/image%2015.png)
    
- 캐시 (cache) : 대역폭 낭비, 응답지연을 방지하기 위해 사본을 임시 저장하는 기술. 웹 브라우저, 중간 서버에 저장.
    
    유효 기간 설정 가능, 날짜(Last-Modified) 혹은 엔티티 태그(Etag) 기반으로 캐시 신선도 재검사. 
    
- 쿠키 (cookie) : 클라이언트의 상태를 알 수 있는 이름, 값, 속성으로 이루어진 정보. 서버에 의해 생성되고 클라이언트가 저장.
- 컨텐츠 협상 (content negotiation) : 같은  URI에 대해 가장 적합한 자원의 표현(송수신 가능한 자원의 형태)을 제공해주는 메커니즘.

# 6장. 실습으로 복습하는 네트워크

- 와이어샤크 (WireShark) : 대중적인 패킷 캡처 프로그램. 캡처된 패킷에 대해 다양한 필터링 가능.
- 패킷 캡쳐 프로그램 (packet capture program) : 네트워크에 송수신되는 패킷을 모니터링하고 분석할 수 있는 프로그램.

# 7장. 네트워크 심화

- 가용성 (availability) : 컴퓨터 시스템이 특정 기능을 실제로 수행할 수 있는 시간의 비율. 전체 사용 시간 중 정상적인 사용 시간.
- 결함 감내 (fault tolerance) : 문제가 발생하더라도 기능할 수 있는 능력.
- 이중화
- 로드 밸런싱 (load balancing) : 로드 밸런서를 이용해 트래픽을 고르게 분배하는 방식.
- 암호화 (encryption) : 원문 데이터를 이해할 수 없는 암호문으로 변형. 암호화에 사용되는 정보는 키.
- 복호화 (decryption) : 암호문을 다시 원문 데이터로 변형하는 것.
- 대칭 키 암호화 (symmetric key cryptography) : 암호화와 복호화 시 같은 키르 사용하는 암호화 방식.
- 공개 키 암호화 (public key cryptography) : 암호화와 복호화 시 서로 다른 키를 사용하는 암호화 방식. 흔히 한 키를 공개 키, 다른 키를 개인 키라 부른다. 한 키로 암호화했다면 다른 키로 복호화할 수 있다.
- 공개 키 인증서 (public key certificate) : 공개 키, 공개 키의 유효성을 입증하기 위한 전자 문서. 공개 키 인증서를 발급하고 검장하는 기관은 CA.
- 디지털 서명(digital signature) : 개인 키로 암호화된메시지를 공개 키로 복호화함을로써 신원을 증명하는 절차.
- TLS (Transport Layer Security) : 인증과 암호화를 수행하는 프로토콜. TLS는 SSL을 계승한 프로토콜. HTTPS는 TLS를 기반으로 인증 및 암호화 수행하는 대표적인 프로토콜. TLS 핸드셰이크를 통해 암호화에 사용할 키, 인증서 주고받을 수 있다.
- 전파 (radio wave) : 무선으로 정보를 주고받는 수단. 전파 통신을 위한 주파수 대역은 정해져 있다.
- IEEE 802.1 (Institute of Electrical and Electronics Engineers 802.11) : 무선 LAN을 위한 표준 규격.
- 와이파이 (Wi-Fi) : 특정 IEEE 802.11 규격을준수하는 무선 LAN 기술.
- 채널 (channel) : 무선 네트워크에서 사용될 특정 주파수 대역. 채널 번호로 구분할 수 있으며 선택된 채널은 겹치는 주파수 대역을 사용하지 않는 것이 좋다.
- AP (Access Point) : 무선 통신 기기들을 연결하여 무선 네트워크를 구성하는 장치. SSID는 AP를 중심으로 구성된 무선 네트워크를 식별하는 정보를 의미.
